# Neon Horizon — iPhone / iOS (Telegram)

Тема для официального клиента **Telegram для iOS (iPhone / iPad)**.

## Содержимое папки

- [`NeonHorizonSynthwave.tgios-theme`](NeonHorizonSynthwave.tgios-theme) — полная тема в официальном формате `.tgios-theme` (палитра Neon Horizon, градиентные исходящие пузыри, реальная неоновая обводка и мягкое свечение вокруг баблов через `stroke` + `shadow`, кольца Stories и встроенный 4-цветный синтвейв-градиент чата).
- [`background_ios.jpg`](background_ios.jpg) — опциональные портретные обои `1290x2796` (под дисплеи iPhone Pro / Pro Max) с Outrun-солнцем, каркасными горами и неоновой сеткой.
- [`VERSION`](VERSION) — текущая версия сборки для iOS.

> **Примечание по фону чата:** формат `.tgios-theme` для iPhone не встраивает локальные JPEG-байты внутрь самого файла темы (поддерживаются только градиенты/цвета или облачные ссылки `t.me/bg/...`), поэтому внутри `.tgios-theme` прописан нативный 4-цветный синтвейв-градиент. При желании поверх темы можно за 2 нажатия поставить картинку `background_ios.jpg`.

## Установка на iPhone

1. Отправьте файл `NeonHorizonSynthwave.tgios-theme` себе в «Избранное» (*Saved Messages*) в Telegram.
2. Нажмите на файл в чате на iPhone и выберите **Применить тему** (*Apply Theme*).
3. *(Опционально)* Чтобы поставить фон с закатом и неоновой сеткой: сохраните [`background_ios.jpg`](background_ios.jpg) в «Фото» и выберите его в **Настройки → Оформление → Обои чата → Выбрать из галереи**.
