# Neon Horizon — Android (Telegram)

Тема для официального клиента **Telegram для Android**.

## Содержимое папки

- [`NeonHorizonSynthwave.attheme`](NeonHorizonSynthwave.attheme) — готовая тема со встроенным портретным фоном `1080x2160` (секция `WPS` / `WPE`) и **775+ настроенными ключами** интерфейса.
- [`NeonHorizonSynthwave-no-bg.attheme`](NeonHorizonSynthwave-no-bg.attheme) — облегчённый вариант без растровой картинки (с глубоким градиентным фоном чата).
- [`background_android.jpg`](background_android.jpg) — исходный портретный фон `1080x2160` в стиле Neon Horizon.
- [`VERSION`](VERSION) — текущая версия сборки для Android.

## Установка

1. Передайте файл `NeonHorizonSynthwave.attheme` на телефон (например, отправьте в «Избранное» / *Saved Messages* через Telegram).
2. Нажмите на файл в чате прямо в Telegram для Android.
3. В окне предпросмотра нажмите **Применить** (*Apply*).
