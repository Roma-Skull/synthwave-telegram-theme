# Neon Horizon — Windows (Telegram Desktop)

Тема для официального клиента **Telegram Desktop (Windows)**.

## Содержимое папки

- [`NeonHorizonSynthwave.tdesktop-theme`](NeonHorizonSynthwave.tdesktop-theme) — готовый к установке архив темы (`colors.tdesktop-theme` + `background.jpg`).
- [`colors.tdesktop-theme`](colors.tdesktop-theme) — полная палитра из **467 официальных цветовых ключей** Telegram Desktop в эстетике Synthwave / Outrun 84.
- [`background.jpg`](background.jpg) — процедурный широкоформатный фон чата `1920x1080` (Outrun-солнце, низкополигональные горы, неоновая сетка и калиброванная яркость под читаемость сообщений).
- [`VERSION`](VERSION) — текущая версия сборки для Windows.

## Установка

1. Отправьте файл `NeonHorizonSynthwave.tdesktop-theme` в «Избранное» (*Saved Messages*) или откройте его двойным кликом / перетаскиванием в окно Telegram Desktop.
2. Нажмите **Применить тему** (*Apply Theme*).

Альтернативный способ: **Настройки → Настройки чатов → ⋮ (меню) → Создать новую тему → Импортировать** и выберите `NeonHorizonSynthwave.tdesktop-theme`.
